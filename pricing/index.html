Engagement Models

Four ways to work together

Choose the structure that fits the task. The written quote confirms the scope, fee, and payment schedule.

01 • Fixed-scope task

One deliverable, one agreed fee

Best for a single output: an AI evaluation batch, rubric calibration, SOP, work instruction, inspection checklist, technical review, or a small VR/MR module.

Billing: one fixed fee. Payment schedule is stated in the written quote before work begins.

02 • Milestone project

Pay as each stage is accepted

Best for multi-stage work: a training module from storyboard to device testing, a documentation set, or project delivery support with clear checkpoints.

Billing: split by approved milestones. Each stage is reviewed before the next begins.

03 • Ongoing QA block

Recurring review capacity

Best for recurring work: AI response QA, data labeling checks, documentation upkeep, or a steady review queue.

Billing: a monthly block agreed in advance, with the expected volume and response time in writing.

04 • Discovery / advisory

Define the task before building

Best when the scope is unclear: a short working session to map inputs, constraints, acceptance criteria, and the smallest useful deliverable.

Billing: quoted separately. You receive a written scope before production work starts.

Before Work Starts

Every quote states the same basics

No verbal-only scope. No surprise add-ons. The written quote is the working agreement for the task.

Deliverable & acceptance criteria
What is produced, and what “done” means.
Inputs & assumptions
What I need from you, and what is excluded.
Revision rounds
The number of review passes included in the fee.
Timeline & dependencies
Delivery window and anything that can move it.
Fee & payment schedule
The amount, currency, and when each payment is due.
Confidentiality
NDA and handling of sensitive inputs, if needed.
Scope changes are re-quoted.

If the task changes materially after approval, I pause, explain the impact, and issue a revised scope. Work continues only after you approve the change.
